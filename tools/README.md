# Mission Studio

Локальный редактор контента для этого сайта.

## Запуск

```bash
npm run studio
```

Открой `http://localhost:4173`.

## Что умеет

- создавать и редактировать миссии RU/EN;
- хранить миссии в `js/missions-ru.js` и `js/missions-en.js`;
- собирать карты мышкой без ручного написания SVG;
- добавлять прямоугольные зоны A/B, полигоны, VP-точки, объекты, линии и подписи;
- сохранять пользовательские карты в `js/maps-custom.js`;
- не трогать старые карты `m1...m12`, пока для них явно не создана custom-карта.

Studio работает только локально и не требует отдельного сервера или базы данных.
